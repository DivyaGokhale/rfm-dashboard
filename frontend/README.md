**Key Features Implemented**

**1. KPI Metrics**
The dashboard includes high-level performance indicators to quickly assess business health:

* **Total Customers** – Number of unique customers
* **Total Revenue** – Overall revenue generated
* **Average Order Value (AOV)** – Revenue per transaction
* **Repeat Customer Percentage** – Customers with multiple purchases

**2. Segment-Level Insights**
Customer segments derived from RFM analysis are further analyzed to extract meaningful insights:

* Revenue contribution of each segment
* Average recency and purchase frequency
* Identification of high-value and at-risk customer groups

**3. Customer Drill-Down Table**
An interactive customer table is implemented to enable detailed analysis:
* Search functionality by Customer ID
* Filter by RFM segment
* Pagination for efficient data viewing (10 rows per page)

**4. Business Recommendations**
Actionable strategies are provided based on customer segmentation:
* **Champions** → Reward loyalty and offer exclusive deals
* **Loyal Customers** → Upsell and cross-sell opportunities
* **At Risk** → Re-engagement campaigns and discounts
* **Hibernating** → Reactivation strategies or reduced marketing focus

## 🛠 **Tech Stack**
* Python (Pandas)
* Matplotlib (for visualizations)
